# RedNote Manager

小红书网页版的批量「取消收藏 / 取消点赞」Chrome 扩展（Manifest V3）。

**Chrome 原生侧边栏操作**：不再遮挡小红书网页。串行执行、随机间隔、批次冷却、连续失败暂停、命中风控立即熔断，并支持一键撤销。

---

## 能做什么

- **AI 智能打标与清理决策 (DeepSeek)**：
  - 支持用户自填 DeepSeek API Key（支持 `deepseek-chat` 与 `deepseek-reasoner` 深度思考模型）；
  - 自动对已缓存的笔记进行语义分析，同时输出**主题分类**（学习干货、美食探店等）与**清理决策辅助属性**：
    - `⚠️ 时效过期`：限时促销、往期优惠、过期招聘、往年攻略等时效失效内容；
    - `📢 营销推广`：软广营销、带货推销内容；
    - `💡 干货保值`：高质量教程、工具代码、实用食谱等值得长期保留的内容；
    - `☕ 普通浏览`：日常随笔与随拍分享。
  - **交互极简丝滑**：分析后自动展开横向滑动胶囊栏。点击胶囊（如 `⚠️ 时效过期`）即刻过滤列表，配合「全选命中」一键勾选，两步完成过期笔记的精准批量取消！
  - **本地持久化缓存**：打标结果持久化保存在本地扩展存储，避免重复请求消耗额度；叠卡速览同步展示 AI 决策理由。
- **叠卡沉浸式速览 (Stack View)**：提供卡片叠放翻阅交互，支持方向键翻页、随机回顾模式、双状态原生态图标（红心/黄星）与自动下一个。
- **Chrome 原生侧边栏**：点击工具栏图标展开/收起 Chrome 原生侧边栏，操作面板与网页并排呈现，阅读与浏览体验更流畅。
- **自动感知用户自主加载**：区别于必须点击「读取列表」的自动探测，用户正常浏览、自主滚动加载的内容会自动、增量并入右侧面板展示（默认为未选状态）。
- **已加载内容即时搜索展示**：对已加载的笔记输入标题、关键词或 ID，下方列表即刻过滤展示命中结果（零延迟本地响应），并联动小红书页面暗化不匹配卡片。
- **页面勾选框与实时条数反馈**：勾选框直接贴在真实卡片左上角（看封面挑选），页面底部配备优雅的浮动反馈栏，勾选/取消勾选/区间选择时**实时反馈已选总条数**与即时提示（Toast），扩展图标 Badge 同步计数。
- **搜索已读取的候选**：标题 / 片段 / id 都能搜，`-词` 排除，纯本地即时过滤。
- **对搜索结果批量处理**：「全选命中」选中当前搜索命中的全部未处理笔记，直接开跑。
- **灵活勾选**：逐条点选、「反选」、「清空」，按住 **Shift** 点击做区间多选。
- **真实执行与安全确认**：每次开始运行均弹出明确的二次确认窗口（条数、间隔、冷却说明），避免误操作。
- **已处理记录落盘**：重跑自动跳过，不会重复操作同一条笔记。
- **撤销上次操作**：误取消时支持一键撤销（重新收藏 / 重新点赞）。

### 页面上的勾选框与底部反馈条

每张笔记卡片左上角会注入一个勾选框，三种状态一眼区分：

| 外观 | 含义 |
|---|---|
| 深色空框 | 未选中 |
| 红色 ✓ + 卡片红描边 | 已勾选（会执行） |
| 绿色 ✓ | 已经处理过（点击无效） |

- 点击勾选框不会打开笔记详情，也不会触发卡片跳转（事件在捕获阶段被截停）
- 按住 **Shift** 点另一张，按页面顺序做区间选择
- 只在「收藏 / 赞过」标签页出现；切到「笔记」子页会自动隐藏
- 搜索时，页面上不匹配的卡片会变暗，方便对照搜索结果挑
- **底部浮动反馈栏**：用户在页面勾选时，底部浮动栏会实时跳动更新已选条数（如 `已选择 5 篇笔记`），并弹出即时提示，附带一键清空和一键展开侧边栏按钮

### 搜索与选择的关系（重要）

两者职责分开，避免「勾了却被隐藏」这类事故：

- **搜索**只决定「列表里显示什么」和「全选命中选中什么」，不隐式扩大或缩小执行范围
- **勾选**才是执行范围：真正发出的请求 = 勾选 ∩ 未处理
- 清空搜索框后勾选仍然保留；若某些已勾选笔记被当前搜索隐藏，工具条会显示 `已选 3 · 隐藏 1`（悬停有说明），它们**仍会被执行**
- 已处理的笔记留在列表里置灰，点它不会改变勾选

## 为什么是这样实现的

| | 候选列表（读） | 取消操作（写） |
|---|---|---|
| 做法 | 解析页面已渲染的笔记卡片 DOM | 通过页面自带签名函数调接口 |
| 为什么 | 列表接口 `/note/like/page`、`/v2/note/collect/page` 即使签名正确也会被风控层拦下（HTTP **461** 空壳响应），因为站点自己的请求还带一个由内部 webpack 模块生成的会话级 `X-S-Common`，外部脚本无法复现 | 写接口只需要 `x-s` / `x-t` 两个头，由页面全局函数 `window._webmsxyw(path, body)` 生成，配合 Cookie 即可 |

MV3 的内容脚本跑在**隔离世界**，看不见页面的 `window._webmsxyw`。所以拆成两层：

```
content.js (隔离世界)  ──postMessage──▶  bridge.js (MAIN world, 页面世界)
   DOM 解析 / 队列 / 限速                 调 _webmsxyw 签名 + fetch 写接口
   页面勾选反馈 / chrome.storage
        │
    runtime 消息
        ▼
sidepanel.js (Chrome 原生侧边栏)
   侧边栏 UI / 统计看板 / 实时日志 / 控制命令
```

接口与字段名：

| 动作 | 路径 | 请求体 |
|---|---|---|
| 取消收藏 | `POST /api/sns/web/v1/note/uncollect` | `{ "note_ids": "<note_id>" }` ← 键名复数，值是**字符串** |
| 取消点赞 | `POST /api/sns/web/v1/note/dislike` | `{ "note_oid": "<note_id>" }` |
| 重新收藏（撤销） | `POST /api/sns/web/v1/note/collect` | `{ "note_id": "<note_id>" }` |
| 重新点赞（撤销） | `POST /api/sns/web/v1/note/like` | `{ "note_oid": "<note_id>" }` |

## 下载与安装

### 方式一：一键下载安装包（小白推荐）
1. 前往 **[GitHub Releases 发布页](https://github.com/willllhuntingggg/RedNote-Manager/releases/latest)** 下载最新版的 **`rednote-manager-v0.3.0.zip`**
2. 解压下载的压缩包（得到一个 `rednote-manager` 文件夹）
3. 打开 Chrome 或 Edge 浏览器，在地址栏输入并回车：`chrome://extensions`
4. 开启页面右上角的「**开发者模式**」开关
5. 点击左上角的「**加载已解压的扩展程序**」，选中刚才解压出的 `rednote-manager` 目录，即可立即使用！

### 方式二：源码安装（开发者）
```bash
git clone https://github.com/willllhuntingggg/RedNote-Manager.git
cd "RedNote Manager"
npm run package  # 可在 dist/ 目录生成最新发布包
```
然后在 `chrome://extensions` 中加载源码目录即可。需要 **Chrome / Edge ≥ 116**（原生 Side Panel API 支持）。

## 使用

1. 打开 `www.xiaohongshu.com` 上**你自己的主页**，切到「收藏」或「赞过」→「笔记」子页
2. 点击浏览器右上角插件图标（或页面底部反馈栏的「展开侧边栏」按钮），右侧会展开 Chrome 原生侧边栏
3. 选模式 → 点「① 读取列表」把候选读进内存
4. 直接在页面上点卡片左上角的勾选框挑封面（底部浮动栏会实时反馈已选条数），或在侧边栏里搜索后用「全选命中」
5. 点「开始」，确认提示框中的条数与安全限速后确认运行
6. 建议先用小批量（如 5–10 篇）跑一次，随时可点「停止」

## 安全边界

| 项 | 默认值 | 硬边界（填超了会被夹住） |
|---|---|---|
| 执行范围 | 你勾选的笔记（勾选 ∩ 未处理） | 必须先勾选，空勾选不会执行 |
| 单条间隔 | 1500–3200 ms（8% 概率额外长停顿 1.5–5 s） | 不得低于 800 ms |
| 单次上限 | 30 篇 | 最多 200 篇 |
| 批次冷却 | 每 20 篇停 45 s | — |
| 并发 | 恒为 1（串行） | 不提供并发选项 |
| 连续失败 | 5 次即暂停 | — |
| 熔断 | HTTP 461/429、`code` 461/-1、响应含「频繁/风控/验证」等字样 → 立即停手 | — |

建议实践：**间隔不低于 1500ms、单次不超过 50 篇、一天别超过几百条**。一旦看到「操作频繁」，至少停 30 分钟，并把间隔调到 3000–6000ms。

## 目录结构

```
manifest.json
src/
  core.js              纯逻辑：设置夹取、接口映射、熔断判定、搜索匹配、区间选择、节律（可单测）
  background.js        Service Worker：原生侧边栏行为绑定 + 默认设置 + 图标 badge
  page/bridge.js       MAIN world：签名代理（ping / me / call）
  content/
    style.js           页面勾选框与底部已选条数反馈栏样式
    content.js         DOM 解析 + 页面勾选 + 底部反馈条 + 引擎 + 与侧边栏通信
  sidepanel/
    sidepanel.html     Chrome 原生侧边栏界面
    sidepanel.css      侧边栏深色主题现代样式
    sidepanel.js       侧边栏状态呈现与指令调度
tests/
  core.test.js         纯逻辑单测（node --test）
  sidepanel_and_feedback.test.js  侧边栏状态与选择条数反馈测试
  dom/                 端到端测试（冒烟 / 边界 / 搜索与选择）
assets/                图标
```
